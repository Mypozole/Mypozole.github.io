# Start Here

This packet is for building the MyPozole website. Read this first, it has the rules that came out of getting some things wrong earlier in planning. Everything else in this packet (Design System, Build Brief, Calendar Guide, Sitemap) is the real content and structure to build from.

## Hard rules, no exceptions

**Never invent a fact.** Every store address, price, or minimum in these docs is verified, either from Jorge directly or from `mypozole.com/retail` and `mypozole.com/online-ordering`. If something is needed that isn't in these docs, leave it visibly marked as missing rather than filling in something plausible-sounding. A blank field gets caught. A wrong one doesn't.

**Real photos only, no AI-generated images.** The photo files included in this packet are real. If a page needs an image that isn't here, use a solid color placeholder in the brand palette, not a generated one.

**Plain English for the three styles.** Always White, Red, Green Pozole on customer-facing pages. Blanco, Rojo, Verde are only used inside the About Pozole education content, and always introduced alongside the plain English name.

**No personal names in operational copy.** Never "Jorge is here Saturday" or "Jorge will get back to you." Use "our team" or "we." Jorge's name and story appear only in the About Pozole page's founding story section.

**No em dashes or en dashes anywhere in site copy.**
